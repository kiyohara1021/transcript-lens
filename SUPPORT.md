# Support

[English](#english) | [日本語](#日本語)

## English

- **Bug:** use the bug report form and include a minimal synthetic JSON example.
- **Feature idea:** use the feature request form and describe the workflow it improves.
- **Security issue:** follow [SECURITY.md](SECURITY.md); never use a public issue.
- **Usage question:** start a GitHub Discussion if Discussions are available; otherwise open an issue with the `question` label.

This is a community-maintained open-source project. Response times are best effort, and there is no service-level agreement.

## 日本語

- **不具合:** Bug Reportフォームを使い、最小限の合成JSONを添えてください。
- **機能案:** Feature Requestフォームを使い、改善したい作業の流れを説明してください。
- **セキュリティ:** [SECURITY.md](SECURITY.md#日本語) に従い、公開Issueには書かないでください。
- **使い方:** Discussionsが利用できる場合はDiscussionを作成し、利用できない場合は `question` ラベル付きIssueを作成してください。

このプロジェクトはコミュニティベースのOSSです。返信は可能な範囲で行い、応答時間の保証はありません。
